# Agent Wiring

Shopify MCP splits into two official products that solve opposite problems, plus community servers that solve neither. This page sorts out which one you were actually looking for.

**Read the full page:** https://shopify-mcp.github.io/

There are two officially documented things under this name and they point in opposite directions: Storefront MCP builds a shopping agent for your customers, while the Shopify AI Toolkit makes your coding assistant competent at Shopify development. Picking the wrong one wastes a sprint, because the storefront path involves an app, a theme extension and a chat window, and the developer path is a plugin install. Neither one automates your admin work unsupervised, and the toolkit is explicit that you choose when a store task executes. If what you actually want is to understand your market rather than wire an assistant into it, Reachara answers that question without touching your store at all.
